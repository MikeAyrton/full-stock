# FULL STOCK GROUP

Готовый адаптивный сайт-визитка на русском языке: Главная, О компании, Услуги, Тарифы, Контакты. Работает без сборки и внешних библиотек.

## Просмотр

Откройте `dist/index.html` в браузере. Для локального сервера выполните `python -m http.server 4173 --directory dist` из папки проекта и откройте http://localhost:4173.

## Содержание

Тексты о компании и услугах подготовлены на основе предоставленного Word. Незаполненная сумма гарантийного фонда, вымышленные партнеры и сотрудники из черновых макетов не размещены. Иллюстрация архитектуры и логотип выполнены в SVG.

Страница тарифов сохраняет структуру предоставленного изображения: шапка, заголовок с подзаголовком, широкий скругленный блок документа, светлый фон и темный подвал. Вместо пустой серой области размещены полностью предоставленные пользователем тарифы. Ставки, пороги и примечания находятся в `dist/tariffs.js`; дата действия сохранена: 01.08.2016. На узких экранах тарифные планы перестраиваются в отдельные блоки без горизонтальной прокрутки.

## Заявки и контакты

Для подключения скачивания сертификатов укажите пути к PDF в массиве `companyCertificates` в начале `dist/app.js`, например `file:'assets/certificates/certificate-01.pdf'`, и положите сам файл по этому пути. Для каждого документа уже предусмотрена кнопка «Скачать». Пока путь не задан, кнопка неактивна и сообщает, что файл пока не добавлен; после задания пути автоматически появится ссылка с атрибутом download. Сертификаты и карточки сотрудников на экранах до 600 px показываются по одному в ряд.

По разрешению пользователя размещены явно отмеченные демонстрационные контакты. Домен `.example` зарезервирован для примеров, почтовые и телефонные ссылки на фиктивные контакты не создаются. Форма проверяет имя, телефон и подтверждение ознакомления с обработкой данных, затем скачивает заявку в TXT. Она не отправляет данные компании и не показывает ложное сообщение об отправке.

Перед запуском приема лидов нужно указать действующие контакты в `dist/app.js` и `dist/index.html`, подключить обработчик отправки заявок, обновить текст формы и разместить действующую политику обработки данных. Контакты и тарифы требуют подтверждения компанией перед публичным запуском.

## Обновление дизайна и курсы валют

Шрифт на всех страницах заменен на Segoe UI с запасными Arial/Helvetica. Первый экран переработан в темно-синей палитре, с обзором услуг и кнопкой консультации.

Верхняя строка на всех пяти вкладках получает USD, EUR, RUB и CNY напрямую из официального JSON API https://cbu.uz/ru/arkhiv-kursov-valyut/json/. Скрипт `dist/rates.js` загружает курсы при открытии страницы, проверяет каждые 5 минут на видимой вкладке, обновляет после возвращения на вкладку и восстановления соединения. Кнопка справа запускает проверку вручную. Дата относится к дате действия курса из поля Date, а не ко времени запроса. Значения приведены в UZS за 1 единицу валюты с учетом Nominal. Подробности и время проверки по Ташкенту показаны в подсказке даты.

Последний успешный ответ сохраняется в localStorage. При недоступности API сохраненные значения помечаются «Кэш», а без кэша выводится сообщение о недоступности, без вымышленных чисел. Доступ к localStorage необязателен. API разрешает CORS, сервер и ключ не требуются; для получения курсов нужен интернет. Изменения оформления находятся в `dist/refinements.css`.

## Размещение

Опубликуйте содержимое `dist/` на любом статическом хостинге. Маршруты используют URL-фрагмент, поэтому настройка перенаправлений не требуется. Инструменты публикации Sites недоступны в этой сессии, сайт подготовлен локально.

Последнее обновление: первый экран с отдельным текстом слева и сгенерированным минималистичным фоном на всю ширину; палитра #00B8FF / #0A2B60 в dist/brand.css. В разделе О компании добавлены 4 места для сертификатов и 4 карточки сотрудников с демонстрационными полями имени, должности, телефона и серыми фото. Промпт и исходник иллюстрации описаны в IMAGEGEN.md.

В форме добавлена услуга «Другое». Адрес в Контактах демонстрационный: Ташкент, проспект Амира Темура, 15. Ссылка «Построить маршрут» открывает Google Maps с этим пунктом назначения; при замене адреса обновите одновременно текст и destination в ссылке. Длинные тире в исходниках сайта заменены обычными дефисами либо текст переформулирован.

Последние правки: прямой заголовок о покупке и продаже акций и облигаций; светло-голубой блок консультации с темно-синей кнопкой; на экранах до 850 px кнопка в шапке скрыта на всех страницах, остаются логотип и бургер. Иллюстрация hero-finance-hd.webp имеет разрешение 5949 x 2379 px; процесс подготовки описан в IMAGEGEN.md.

Тарифный документ полностью набран Segoe UI 16 px, включая примечания и консультационные услуги; заголовки крупнее. До 1200 px четыре плана показываются отдельными карточками с двухколоночной таблицей суммы и ставки и примечанием под ней; до 650 px карточки и бесплатные депозитарные услуги идут последовательно в одну колонку. Все представления используют одни исходные данные в tariffs.js. Проверено отсутствие горизонтальной прокрутки при 979 и 320 px.
